# 💡 Lamba ve Kalp Animasyonu (Pygame)
![Lamba Kalp Animasyonu Demo](demo.gif)

Bu proje, **Pygame** kütüphanesi kullanılarak geliştirilmiş interaktif bir animasyon uygulamasıdır. 

## 🎯 Özellikler
- 💡 Açılıp kapanabilen interaktif lamba düzeneği.
- 🏹 Lamba açıldığında pürüzsüz bir ok animasyonu ile kalp çizimi.
- ✨ Çizim tamamlandığında beliren "I LOVE YOU" yazısı.

## 🛠️ Kurulum

Projeyi çalıştırmak için Pygame kütüphanesinin yüklü olması gerekir:

```bash
pip install pygame
